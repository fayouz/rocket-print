La démo lance Rocket Print avec des données prêtes à l'emploi :

- des comptes locaux et LDAP (annuaire OpenLDAP) ;
- deux imprimantes : **Accueil (dossier de démo)**, qui écrit les documents dans un dossier, et **Laser 2e étage (Samba)**, sur un vrai serveur d'impression Samba (service `print-server`) ;
- deux impressions d'Alice ;
- une application externe, avec un jeton connu, qui peut imprimer au nom des utilisateurs.

::tabs
  :::tabs-item{label="En local" icon="i-lucide-laptop"}
  ```bash [Terminal]
  docker compose -f compose.yaml -f compose.demo.yaml up -d --build
  ```

  Puis ouvrez http://localhost:3300 (Rocket Print) et http://localhost:3301 (cette documentation et le changelog).
  :::

  :::tabs-item{label="GitHub Codespaces" icon="i-simple-icons-github"}
  1. Sur GitHub : **Code → Codespaces → Create codespace**.
  2. Attendez la fin de la commande de démarrage (quelques minutes la première fois).
  3. Ouvrez le port 3300 (Rocket Print) depuis l'onglet **Ports**.
  :::
::

## Comptes

| Compte | Mot de passe | Type |
|---|---|---|
| `admin@example.org` | `demo-admin-password` | local, administrateur |
| `alice@example.org` | `demo-alice-password` | local |
| `marie.martin@example.org` | `password` | LDAP, administratrice par son groupe |
| `jean.dupont@example.org` | `password` | LDAP |

## Scénarios

1. **Imprimer.** Connectez-vous avec `alice@example.org`, ouvrez **Imprimer**, déposez un PDF, choisissez « Laser 2e étage (Samba) » et 2 exemplaires. Dans **Mes impressions**, le document passe en « Imprimé ». Il est arrivé sur le serveur d'impression :
   ```bash [Terminal]
   docker compose -f compose.yaml -f compose.demo.yaml exec print-server ls -l /printed
   ```
2. **Panne d'imprimante.** Arrêtez le serveur d'impression (`docker compose -f compose.yaml -f compose.demo.yaml stop print-server`) et imprimez : le document reste « En attente » entre les tentatives, puis passe en « Échec ». Redémarrez le serveur (`start print-server`) et cliquez sur **Réimprimer**.
3. **Administration.** Avec `admin@example.org`, ouvrez **Imprimantes** : testez la connexion, imprimez une page de test, ajoutez une imprimante. Le tableau de bord montre l'état des imprimantes.
4. **Application.** Une application imprime au nom d'Alice :
   ```bash [Terminal]
   curl -X POST http://localhost:3300/api/print-jobs \
     -H "Authorization: Bearer rpa_demo_rocket_print_do_not_use_in_production" \
     -H "X-Impersonate-User: alice@example.org" -H "Accept: application/json" \
     -F file=@document.pdf
   ```
   Le document apparaît dans les impressions d'Alice, avec le nom de l'application.

::warning
Les mots de passe et le jeton de la démo sont publics : ne l'exposez pas sur Internet.
::
