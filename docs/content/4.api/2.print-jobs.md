Toutes les requêtes demandent un utilisateur : un JWT, ou une application qui impersonne un utilisateur (`Authorization: Bearer rpa_…` + `X-Impersonate-User`). Voir [Authentification](/api/authentication).

## Lister les imprimantes

```bash [Terminal]
curl https://print.exemple.com/api/printers -H "Authorization: Bearer …" -H "Accept: application/json"
```

```json
[
  {
    "id": "0199…",
    "name": "Laser 2e étage",
    "description": null,
    "location": "2e étage, open space",
    "connectorLabel": "Partage Windows / Samba",
    "colorSupported": false,
    "duplexSupported": true,
    "defaultPrinter": true,
    "enabled": true
  }
]
```

Seules les imprimantes actives sont listées, sans leurs paramètres de connexion.

## Imprimer

`POST /api/print-jobs`, en `multipart/form-data` :

| Champ | Rôle | Défaut |
|---|---|---|
| `file` | Le document : PDF, PostScript, PCL, JPEG, PNG ou texte | requis |
| `printer` | Identifiant de l'imprimante (ou `/api/printers/<id>`) | l'imprimante par défaut |
| `copies` | Nombre d'exemplaires, de 1 à 99 | `1` |
| `duplex` | `1` : recto verso (ignoré si l'imprimante ne le fait pas) | `0` |
| `color` | `1` : couleur (ignoré si l'imprimante ne le fait pas) | `0` |
| `title` | Nom du document dans la file | nom du fichier |

```bash [Terminal]
curl -X POST https://print.exemple.com/api/print-jobs \
  -H "Authorization: Bearer rpa_…" \
  -H "X-Impersonate-User: alice@exemple.com" \
  -H "Accept: application/json" \
  -F file=@facture-2026-042.pdf \
  -F printer=0199… -F copies=2 -F duplex=1
```

La réponse (`201`) est le travail d'impression, en file d'attente :

```json
{
  "id": "01a0…",
  "title": "facture-2026-042.pdf",
  "mimeType": "application/pdf",
  "size": 48213,
  "printerId": "0199…",
  "printerName": "Laser 2e étage",
  "ownerEmail": "alice@exemple.com",
  "applicationName": "CRM",
  "copies": 2,
  "duplex": true,
  "color": false,
  "status": "queued",
  "attempts": 0,
  "error": null,
  "externalId": null,
  "printedAt": null,
  "contentPurged": false,
  "cancellable": true,
  "retryable": false,
  "createdAt": "2026-09-25T10:12:00+00:00"
}
```

| Erreur | Cause |
|---|---|
| `413` | Document trop gros (`PRINT_MAX_FILE_SIZE`) |
| `422` | Format non accepté, document vide, nombre d'exemplaires invalide, imprimante inconnue ou désactivée, pas d'imprimante par défaut |
| `403` | Application sans utilisateur (`X-Impersonate-User` manquant) |

`GET /api/print-jobs/settings` renvoie la taille maximale et les formats acceptés.

## Suivre une impression

```bash [Terminal]
curl https://print.exemple.com/api/print-jobs/01a0… -H "Authorization: Bearer …" -H "Accept: application/json"
```

| `status` | Signification |
|---|---|
| `queued` | En file d'attente, ou entre deux tentatives |
| `printing` | En cours d'envoi à l'imprimante |
| `printed` | Accepté par l'imprimante ou le serveur d'impression. `externalId` : la référence qu'il a donnée (numéro de travail IPP…), `printedAt` : l'heure |
| `failed` | Échec après 3 tentatives, ou échec définitif (identifiants refusés, format refusé…) : voir `error` |
| `cancelled` | Annulé avant l'impression |

::note
`printed` signifie que l'imprimante ou le serveur d'impression a **accepté** le document. Un bourrage papier ou un bac vide se voient sur l'imprimante, pas dans Rocket Print.
::

## Lister les impressions

`GET /api/print-jobs` liste les travaux de l'utilisateur, du plus récent au plus ancien. Filtres : `status`, `printer`, `title` (recherche partielle), pagination `page` et `itemsPerPage`. Un administrateur voit tous les travaux avec `?all=1`.

## Annuler, réimprimer, relire

| Requête | Effet |
|---|---|
| `POST /api/print-jobs/{id}/cancel` | Annule un travail encore en file (`cancellable`). Sinon `409`. |
| `POST /api/print-jobs/{id}/retry` | Réimprime un travail en échec ou annulé (`retryable`), avec de nouvelles tentatives. Sinon `409`. |
| `GET /api/print-jobs/{id}/content` | Le document, tant qu'il est conservé (`PRINT_RETENTION_DAYS`). Ensuite `404`. |

Ces actions sont réservées au propriétaire du travail et aux administrateurs ; pour les autres, le travail n'existe pas (`404`).
