Rocket Print est la brique d'impression du Middleware Rocket. Il sert à la fois :

- d'**application** : vos collaborateurs déposent un document, choisissent une imprimante et suivent leurs impressions ;
- de **brique d'intégration** : vos autres applications (CRM, ERP, portail…) impriment par l'API au nom de leurs utilisateurs, sans connaître les imprimantes ni leurs identifiants.

## Architecture

| Élément | Technologie | Rôle |
|---|---|---|
| API | Symfony 8, API Platform 5, PostgreSQL | Authentification, utilisateurs, applications, imprimantes, travaux d'impression |
| Worker | Symfony Messenger et Scheduler | Envoi des documents aux imprimantes, vérifications périodiques, nettoyage |
| Front | Nuxt 4, Nuxt UI 4 | Impression, suivi, administration |
| Documentation | Nuxt Content | Ce site, et le changelog |

Rocket Print partage sa stack et son socle (comptes, LDAP, SSO, applications, tableau de bord, mises à jour) avec les autres briques Rocket : Rocket Mailer, Rocket Auth, Rocket Cloud et Rocket Doc Fusion.

## Cycle de vie d'une impression

1. Le document est déposé (interface ou `POST /api/print-jobs`) : Rocket Print vérifie son format et sa taille, le stocke, et crée un travail `queued`.
2. Le worker l'envoie à l'imprimante par son connecteur : le travail passe en `printing`, puis `printed`.
3. En cas d'échec passager (serveur injoignable, imprimante occupée), il retente 1 minute puis 5 minutes plus tard. Après 3 tentatives, ou tout de suite si l'échec est définitif (identifiants refusés, format refusé), le travail passe en `failed` avec le message d'erreur.
4. Un travail en attente peut être annulé (`cancelled`) ; un travail en échec ou annulé peut être réimprimé.
5. Les documents sont supprimés `PRINT_RETENTION_DAYS` jours après l'impression (7 par défaut). L'historique, lui, est conservé.

## Formats acceptés

PDF, PostScript, PCL, JPEG, PNG et texte. Rocket Print ne convertit pas les documents :

- en **IPP**, les imprimantes récentes (IPP Everywhere, AirPrint) acceptent directement PDF et JPEG ; une file CUPS convertit ce que ses filtres connaissent ;
- en **Samba**, le document est transmis tel quel : l'imprimante, ou le pilote du serveur d'impression, doit comprendre son format. PDF et PostScript conviennent aux imprimantes laser récentes, PCL à la plupart des autres.

Pour imprimer un document Office, convertissez-le d'abord en PDF, par exemple avec Rocket Doc Fusion.

## Traçabilité

Chaque travail garde son propriétaire, l'application qui l'a envoyé, l'imprimante, les options, le nombre de tentatives et la dernière erreur. Toutes les entités enregistrent leur date et leur auteur de création et de modification (`createdAt`, `createdBy`…).
