Rocket Print est un service d'envoi d'emails pour votre organisation. Il sert à la fois :

- d'**application** : vos collaborateurs composent leurs emails en texte enrichi, importent des templates et retrouvent leurs envois ;
- de **brique d'intégration** : vos autres applications (CRM, ERP, portail client…) affichent le même composeur dans leurs propres pages, ou envoient des emails par API, **au nom de l'utilisateur connecté**.

## Architecture

| Brique | Technologie | Rôle |
|---|---|---|
| API | Symfony 8, API Platform 5, PostgreSQL | Authentification, utilisateurs, applications, emails, templates |
| Worker | Symfony Messenger | Envoi asynchrone des emails (SMTP) |
| Front | Nuxt 4, Nuxt UI 4 | Application web, page d'embed `/embed/compose`, widget `embed.js` |
| Annuaire | LDAP (optionnel) | Connexion et synchronisation des comptes |

Les emails sont d'abord enregistrés avec le statut `queued`, puis envoyés par le worker, qui les passe en `sent` ou `failed`.

## Traçabilité

Toutes les entités enregistrent leur date de création et de modification (`createdAt`, `updatedAt`), ainsi que leur auteur (`createdBy`, `updatedBy`). Chaque email garde l'**utilisateur** au nom duquel il a été envoyé et, le cas échéant, l'**application** qui l'a envoyé. Les templates sont en plus **versionnés** : chaque modification crée une version restaurable.
