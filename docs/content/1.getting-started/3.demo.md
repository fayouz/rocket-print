La démo lance Rocket Print avec des données prêtes à l'emploi :

- des comptes locaux et LDAP ;
- deux templates partagés ;
- **Démo CRM**, une fausse application tierce qui embarque le composeur. C'est le meilleur moyen de voir l'intégration en action ;
- la **boîte d'envoi** « Boîte commerciale du CRM » (`commercial@crm.example.org`), rattachée à Démo CRM. Ses emails passent par Mailpit, et leurs copies sont rangées dans le dossier « Sent » d'un serveur IMAP de test (GreenMail, `localhost:3143`, identifiant `commercial`, mot de passe `secret-pass`).

::tabs
  :::tabs-item{label="GitHub Codespaces" icon="i-simple-icons-github"}
  1. Sur GitHub : **Code → Codespaces → Create codespace**.
  2. Attendez la fin de la commande de démarrage (5 à 10 minutes la première fois). Elle affiche les URLs.
  3. Ouvrez les ports 3000 (Rocket Print), 4000 (Démo CRM), 3001 (cette documentation et le changelog) et 8025 (Mailpit) depuis l'onglet **Ports**.
  :::

  :::tabs-item{label="En local" icon="i-lucide-laptop"}
  ```bash [Terminal]
  docker compose -f compose.yaml -f compose.demo.yaml up -d --build
  ```

  Puis ouvrez http://localhost:3000, http://localhost:4000, http://localhost:3001 (documentation) et http://localhost:8025.
  :::
::

## Tester l'intégration

Sur **Démo CRM** (port 4000) :

1. choisissez l'utilisateur « connecté au CRM » : le composeur envoie en son nom ;
2. cliquez sur **Écrire à ce client** : l'expéditeur (« Service commercial », une adresse que le CRM est autorisé à imposer), le destinataire et l'objet sont pré-remplis (`setDraft`) ;
3. cliquez sur **Envoyer le devis (PDF joint)** : le CRM génère un PDF, le joint au nom de l'utilisateur et le passe au composeur ;
4. importez un template, envoyez, et suivez les événements du widget dans le journal ; l'email et sa pièce jointe arrivent dans Mailpit.

Le code de Démo CRM (`demo/host/server.mjs`) est un exemple complet et minimal d'intégration : un endpoint serveur qui génère les jetons, et une page qui appelle `RocketMailer.mount()`.

::caution
Les mots de passe et le jeton d'application de la démo sont publics. N'exposez jamais la démo durablement sur Internet.
::
