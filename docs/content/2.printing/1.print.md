## Imprimer un document

1. Ouvrez **Imprimer**.
2. Déposez le document dans la zone prévue, ou cliquez pour le choisir. Formats : PDF, PostScript, PCL, JPEG, PNG et texte.
3. Choisissez l'imprimante : l'imprimante par défaut est présélectionnée. Son emplacement s'affiche sous la liste.
4. Réglez le nombre d'exemplaires, et le recto verso ou la couleur si l'imprimante les propose.
5. Cliquez sur **Imprimer** : le document part dans la file de l'imprimante et vous arrivez sur **Mes impressions**.

::tip
Pour un document Word, Excel ou LibreOffice, enregistrez-le d'abord en PDF : c'est le format que les imprimantes comprennent le mieux.
::

## Suivre ses impressions

**Mes impressions** liste vos documents, les plus récents en premier, avec leur statut :

| Statut | Signification |
|---|---|
| En attente | Dans la file, ou en attente d'une nouvelle tentative |
| En cours | En cours d'envoi à l'imprimante |
| Imprimé | Accepté par l'imprimante |
| Échec | L'imprimante n'a pas pu être jointe ou a refusé le document ; survolez le statut pour voir pourquoi |
| Annulé | Annulé avant l'impression |

La page se met à jour toute seule tant qu'un document est en attente ou en cours. Depuis la liste, vous pouvez :

- **voir** le document envoyé (tant qu'il est conservé, 7 jours par défaut) ;
- **annuler** un document encore en attente ;
- **réimprimer** un document en échec ou annulé, par exemple après la réparation de l'imprimante.

Les documents envoyés par une application (CRM, ERP…) en votre nom apparaissent aussi, avec le nom de l'application.
