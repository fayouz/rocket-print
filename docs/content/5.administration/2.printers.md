Les imprimantes se gèrent dans **Administration → Imprimantes**. Chaque imprimante a un nom, un emplacement et une description (montrés aux utilisateurs), un **connecteur** et une adresse, et ses options : recto verso, couleur, imprimante par défaut, active.

Les utilisateurs ne voient que les imprimantes actives, sans leur adresse ni leurs identifiants.

## Connecteurs

### Partage Windows / Samba

Pour une imprimante partagée par un serveur d'impression Windows ou Samba. Rocket Print l'utilise avec `smbclient` (commande `print`), comme un poste de travail.

| Champ | Exemple |
|---|---|
| Adresse | `//serveur-impression/Laser-2e` (aussi `smb://serveur-impression/Laser-2e` ou `\\serveur-impression\Laser-2e`). Un port : `//serveur:1445/Laser-2e`. |
| Utilisateur, mot de passe | Un compte de service autorisé à imprimer sur ce partage. Vide : connexion anonyme. |
| Domaine | Le domaine Active Directory ou le groupe de travail, ex. `ACME` ou `WORKGROUP` |

Le document est transmis **tel quel** : l'imprimante, ou le pilote du serveur, doit comprendre son format. PDF et PostScript conviennent aux imprimantes laser récentes, PCL à la plupart des autres. Recto verso et couleur ne peuvent pas être transmis par ce connecteur : ce sont les réglages par défaut de l'imprimante sur le serveur qui s'appliquent.

**Tester la connexion** liste les partages du serveur et vérifie que l'adresse désigne bien une imprimante.

### IPP / CUPS

Pour une imprimante réseau (IPP Everywhere, AirPrint : la plupart des imprimantes récentes) ou une file d'un serveur CUPS.

| Cas | Adresse |
|---|---|
| Imprimante réseau | `ipp://imprimante.local/ipp/print` (sans chemin : `/ipp/print`) |
| Avec TLS | `ipps://imprimante.local/ipp/print` |
| File CUPS | `ipp://cups.exemple.lan:631/printers/laser-2e` |

Le port par défaut est 631. Utilisateur et mot de passe, si l'imprimante ou CUPS en demandent, passent en authentification HTTP Basic : préférez alors `ipps://`.

Le connecteur transmet le nombre d'exemplaires, le recto verso (`sides`) et la couleur (`print-color-mode`) quand l'imprimante les propose. Si l'imprimante refuse ces options, le document est réimprimé avec ses réglages par défaut. **Tester la connexion** interroge l'état de l'imprimante (prête, occupée, arrêtée) et son modèle.

::note
Avec `ipps://`, le certificat de l'imprimante doit être reconnu par le serveur. Beaucoup d'imprimantes ont un certificat autosigné : installez-le dans le magasin de certificats de l'image, ou utilisez `ipp://` sur un réseau de confiance.
::

### Dossier (test)

Écrit les documents dans un sous-dossier de `PRINT_FOLDER_ROOT` (ex. `tests` ou `archives/2026`), avec leurs options dans un fichier `.json` à côté. Pour essayer Rocket Print sans imprimante, pour les tests, ou pour archiver ce qui aurait été imprimé.

## Tester

Pour chaque imprimante :

- **Tester la connexion** vérifie que l'imprimante répond, sans rien imprimer ;
- **Imprimer une page de test** envoie une page PDF avec le nom de l'imprimante, la date et votre nom. Elle apparaît dans vos impressions.

Les imprimantes actives sont aussi vérifiées toutes les 5 minutes par le worker. Le résultat apparaît dans l'**état des services** du [tableau de bord](/administration/dashboard) : une imprimante injoignable passe le service « Imprimantes » en dégradé.

## Imprimante par défaut

Une seule imprimante est l'imprimante par défaut : en choisir une autre retire l'option à la précédente. Elle est présélectionnée sur la page **Imprimer**, et utilisée par l'API quand une application n'indique pas d'imprimante.

## Supprimer ou désactiver

Désactiver une imprimante la retire de la liste des utilisateurs ; les documents encore en file échouent. La supprimer garde l'historique des impressions passées, avec le nom de l'imprimante.

## Sécurité

- Les mots de passe des imprimantes sont **chiffrés** en base (`SECRETS_ENCRYPTION_KEY`, ou dérivée de `APP_SECRET`) et ne sont **jamais renvoyés** par l'API. Laissez le champ vide pour garder le mot de passe enregistré.
- Le connecteur Samba passe les identifiants à `smbclient` par un fichier temporaire lisible par le seul processus (mode `0600`), supprimé aussitôt : ils n'apparaissent jamais dans la liste des processus.
- Les documents sont stockés sous un nom opaque et supprimés après `PRINT_RETENTION_DAYS` jours. Seuls leur propriétaire et les administrateurs peuvent les relire.
- Les applications impriment au nom d'un utilisateur, sans jamais connaître les imprimantes ni leurs identifiants.
